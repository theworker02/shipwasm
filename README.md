# shipwasm

Ship and reshape wasm text streams with deterministic transforms.

**Site:** https://theworker02.github.io/shipwasm/

## Install / run

```bash
git clone https://github.com/theworker02/shipwasm.git
cd shipwasm
node src/cli.js
node --test
```
